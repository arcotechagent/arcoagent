How Arco Works

Perceive. Reason. Act. Remember. Repeat.

01

Perceive

Every message, file, webhook, and on-chain event lands in one ingestion loop — normalized, timestamped, and ranked before an agent ever sees it.

40+ connectors live
→
02

Reason

A router scores the task and picks the cheapest model that can actually do it, escalating up the chain only when confidence drops.

12 model providers
→
03

Act

Tool calls run inside a sandbox tier matched to the risk — read-only, write-scoped, or fully isolated — before anything touches a live system.

3 sandbox tiers
→
04

Remember

Outcomes compress into durable memory and get indexed, so the next run starts already knowing what the last one learned.

2.1B embeddings stored

↳ then back to Perceive — the loop never fully closes, it just gets faster.

#2 Remember

Disciplined Automation
